
| Código   | Nombre                                                    | Descripción                                                                                                                                                                                                                                                          |
| -------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RF-001   | Gestión de Productos                                      | El sistema deberá permitir al supervisor llevar a cabo la gestión del catálogo de productos del negocio.                                                                                                                                                             |
| RF-001.1 | Registrar producto                                        | El sistema deberá permitir al supervisor registrar un nuevo producto con nombre, categoría, unidad de venta, precio de venta y stock mínimo. La fecha de vencimiento no se registra en el producto sino en el Lote al momento de cada entrada de mercancía.          |
| RF-001.2 | Consultar producto                                        | El sistema deberá permitir al supervisor consultar el listado de productos registrados con filtros por nombre, categoría, unidad de venta, estado y proveedor.                                                                                                       |
| RF-001.3 | Actualizar producto                                       | El sistema deberá permitir al supervisor modificar la información de un producto existente. Toda modificación del precio de venta genera automáticamente un registro en HistorialPrecio con el usuario y la fecha y hora del cambio.                                 |
| RF-001.4 | Inactivar producto                                        | El sistema deberá permitir al supervisor desactivar un producto del catálogo, impidiendo su uso en nuevas ventas y entradas de mercancía.                                                                                                                            |
| RF-002   | Gestión de Lotes y Entradas de Mercancía                  | El sistema deberá permitir al supervisor gestionar las entradas de mercancía y los lotes asociados a cada producto.                                                                                                                                                  |
| RF-002.1 | Registrar entrada de mercancía                            | El sistema deberá permitir al supervisor registrar una entrada de mercancía especificando producto, proveedor, número de factura, cantidad, precio de costo y fecha de vencimiento, generando automáticamente un lote asociado.                                      |
| RF-002.2 | Consultar lotes activos                                   | El sistema deberá permitir al supervisor consultar los lotes activos de un producto con filtros por estado, fecha de vencimiento y proveedor.                                                                                                                        |
| RF-002.3 | Ajustar inventario                                        | El sistema deberá permitir al supervisor realizar ajustes manuales sobre un lote específico registrando el motivo (PERDIDA, DAÑO, ROBO, VENCIMIENTO, DEVOLUCION, CORRECCION) y el usuario responsable.                                                               |
| RF-002.4 | Consultar movimientos de inventario                       | El sistema deberá permitir al supervisor consultar el historial de movimientos del inventario con filtros por producto, lote, fecha y tipo de movimiento.                                                                                                            |
| RF-003   | Gestión de Proveedores                                    | El sistema deberá permitir al supervisor gestionar los proveedores del negocio.                                                                                                                                                                                      |
| RF-003.1 | Registrar proveedor                                       | El sistema deberá permitir al supervisor registrar un nuevo proveedor con nombre comercial, tipo de documento, número de documento, nombre de contacto, teléfono y correo electrónico.                                                                               |
| RF-003.2 | Consultar proveedor                                       | El sistema deberá permitir al supervisor consultar los proveedores registrados con filtros por nombre y estado.                                                                                                                                                      |
| RF-003.3 | Actualizar proveedor                                      | El sistema deberá permitir al supervisor modificar la información de un proveedor existente.                                                                                                                                                                         |
| RF-003.4 | Inactivar proveedor                                       | El sistema deberá permitir al supervisor desactivar un proveedor, impidiendo su asociación a nuevas entradas de mercancía.                                                                                                                                           |
| RF-004   | Gestión de Ventas                                         | El sistema deberá permitir al cajero gestionar las ventas realizadas en el punto de venta.                                                                                                                                                                           |
| RF-004.1 | Registrar venta                                           | El sistema deberá permitir al cajero registrar una venta con uno o varios productos, aplicando el precio configurado y el descuento activo si existe, con cálculo automático del total y el cambio.                                                                  |
| RF-004.2 | Consultar venta                                           | El sistema deberá permitir al administrador consultar el historial de ventas con filtros por fecha, producto, cajero y método de pago.                                                                                                                               |
| RF-004.3 | Cancelar venta                                            | El sistema deberá permitir al cajero cancelar una venta en curso antes de confirmar el pago sin afectar el inventario.                                                                                                                                               |
| RF-004.4 | Generar comprobante de venta                              | El sistema deberá permitir al cajero generar un comprobante digital de la venta con detalle de productos, cantidades, precios, descuentos aplicados y total.                                                                                                         |
| RF-005   | Gestión de Caja                                           | El sistema deberá permitir al cajero gestionar el turno de caja incluyendo apertura, cierre y consulta de diferencias.                                                                                                                                               |
| RF-005.1 | Registrar apertura de caja                                | El sistema deberá permitir al cajero registrar la apertura de caja con usuario, fecha, hora exacta y monto inicial declarado. Este registro es inmodificable una vez guardado.                                                                                       |
| RF-005.2 | Registrar cierre de caja                                  | El sistema deberá permitir al cajero registrar el cierre de caja con el total de ventas del turno y el monto final declarado, calculando automáticamente la diferencia.                                                                                              |
| RF-005.3 | Consultar historial de cierres de caja                    | El sistema deberá permitir al administrador consultar el historial de aperturas y cierres de caja con filtros por fecha y cajero.                                                                                                                                    |
| RF-005.4 | Consultar diferencias de caja                             | El sistema deberá permitir al administrador consultar la diferencia entre el dinero esperado según ventas y el monto declarado al cierre.                                                                                                                            |
| RF-006   | Gestión de Descuentos                                     | El sistema deberá permitir al administrador gestionar los descuentos sobre productos próximos a vencer.                                                                                                                                                              |
| RF-006.1 | Generar propuesta de descuento                            | El sistema deberá generar automáticamente una propuesta de descuento para los productos con lotes próximos a vencer según el umbral configurado en la categoría.                                                                                                     |
| RF-006.2 | Aprobar descuento                                         | El sistema deberá permitir al administrador aprobar o ajustar el porcentaje de descuento propuesto, verificando que no supere el margen de rentabilidad del lote.                                                                                                    |
| RF-006.3 | Consultar historial de descuentos                         | El sistema deberá permitir al administrador consultar el historial de descuentos con filtros por producto, lote, estado y fecha.                                                                                                                                     |
| RF-006.4 | Inactivar descuento                                       | El sistema deberá permitir al administrador desactivar un descuento activo antes de su vencimiento.                                                                                                                                                                  |
| RF-007   | Gestión de Usuarios y Acceso                              | El sistema deberá permitir al administrador gestionar los usuarios del sistema y controlar el acceso según el rol asignado.                                                                                                                                          |
| RF-007.1 | Registrar usuario                                         | El sistema deberá permitir al administrador registrar un nuevo usuario con nombre, tipo de documento, número de documento, correo electrónico, rol y contraseña.                                                                                                     |
| RF-007.2 | Consultar usuario                                         | El sistema deberá permitir al administrador consultar los usuarios registrados con filtros por nombre, rol y estado.                                                                                                                                                 |
| RF-007.3 | Actualizar usuario                                        | El sistema deberá permitir al administrador modificar la información de un usuario existente.                                                                                                                                                                        |
| RF-007.4 | Inhabilitar usuario                                       | El sistema deberá permitir al administrador inhabilitar las credenciales de un usuario, impidiendo su acceso al sistema sin eliminar su historial de operaciones.                                                                                                    |
| RF-007.5 | Iniciar sesión                                            | El sistema deberá permitir a cualquier usuario registrado iniciar sesión mediante tipo de documento, número de documento y contraseña, redirigiendo al panel correspondiente según su rol (Administrador, Supervisor, Cajero).                                       |
| RF-007.6 | Cerrar sesión                                             | El sistema deberá permitir a cualquier usuario cerrar su sesión activa de forma segura.                                                                                                                                                                              |
| RF-007.7 | Cambiar contraseña                                        | El sistema deberá permitir a un usuario autenticado cambiar su contraseña ingresando la contraseña actual y la nueva. El sistema notificará por correo al usuario que su contraseña fue modificada, como medida de seguridad. |
| RF-008   | Gestión de Alertas de Inventario                          | El sistema deberá permitir al supervisor configurar los umbrales de alerta y generar notificaciones automáticas sobre el estado del inventario.                                                                                                                      |
| RF-008.1 | Configurar umbral de stock mínimo                         | El sistema deberá permitir al supervisor configurar el nivel mínimo de stock por producto a partir del cual se dispara una alerta de bajo inventario.                                                                                                                |
| RF-008.2 | Configurar umbral de vencimiento                          | El sistema deberá permitir al supervisor configurar los días de anticipación a partir de los cuales se genera una alerta de vencimiento por categoría de producto.                                                                                                   |
| RF-008.3 | Generar alerta de bajo stock                              | El sistema deberá generar automáticamente una alerta visual cuando un producto alcance o caiga por debajo de su nivel mínimo de stock configurado.                                                                                                                   |
| RF-008.4 | Generar alerta de vencimiento próximo                     | El sistema deberá generar automáticamente una alerta visual cuando un lote esté próximo a vencer según el umbral configurado en su categoría.                                                                                                                        |
| RF-009   | Gestión de Recomendaciones de Compra                      | El sistema deberá generar recomendaciones de compra basadas en la velocidad de venta, el estado del inventario y los vencimientos de los lotes activos.                                                                                                              |
| RF-009.1 | Calcular velocidad de venta                               | El sistema deberá calcular la velocidad de venta de cada producto expresada en unidades vendidas por día en un período configurable.                                                                                                                                 |
| RF-009.2 | Estimar días de cobertura                                 | El sistema deberá estimar los días que durará el stock actual de cada producto cruzando el inventario disponible con la velocidad de venta promedio.                                                                                                                 |
| RF-009.3 | Identificar productos en riesgo de vencimiento anticipado | El sistema deberá identificar los productos cuya fecha de vencimiento llegará antes de que puedan venderse al ritmo de venta actual.                                                                                                                                 |
| RF-009.4 | Generar lista de reposición priorizada                    | El sistema deberá generar automáticamente una lista de productos a reponer ordenada por nivel de urgencia con cantidad sugerida, proveedor asociado y valor estimado del pedido.                                                                                     |
| RF-009.5 | Visualizar historial de ventas por producto               | El sistema deberá permitir visualizar el historial de volumen de ventas por producto con los días de mayor demanda.                                                                                                                                                  |
| RF-010   | Gestión de Indicadores y Reportes                         | El sistema deberá permitir al administrador consultar los indicadores clave del negocio a través de paneles centralizados.                                                                                                                                           |
| RF-010.1 | Visualizar dashboard de inventario                        | El sistema deberá permitir al administrador visualizar el estado del inventario con stock actual, lotes próximos a vencer y productos en nivel crítico.                                                                                                              |
| RF-010.2 | Visualizar dashboard de ventas                            | El sistema deberá permitir al administrador visualizar los indicadores de ventas del día: ingresos totales, productos más vendidos y estado del cierre de caja.                                                                                                      |
| RF-010.3 | Visualizar dashboard de recomendaciones                   | El sistema deberá permitir al administrador visualizar las recomendaciones de compra priorizadas por urgencia con cantidad sugerida, proveedor asociado e historial de descuentos recientes.                                                                         |
| RF-010.4 | Consultar resumen de ingresos diarios                     | El sistema deberá permitir al administrador consultar un resumen de ingresos del día con detalle por producto y comparativo con el día anterior.                                                                                                                     |
| RF-011   | Gestión de Operación Offline y Sincronización             | El sistema deberá permitir a los usuarios operar sin conexión a internet y sincronizar automáticamente los datos generados localmente al restablecer la conexión, garantizando la continuidad del negocio ante fallos de red.                                        |
| RF-011.1 | Registrar operaciones en modo offline                     | El sistema deberá permitir al cajero, supervisor y administrador registrar ventas, ajustes de inventario y entradas de mercancía sin conexión, almacenando cada operación localmente con identificador único y marca de tiempo hasta que se restablezca la conexión. |
| RF-011.2 | Sincronizar datos con el servidor                         | El sistema deberá sincronizar automáticamente todas las operaciones registradas localmente con el servidor al detectar conexión, sin requerir intervención manual, procesándolas en orden cronológico y notificando al usuario el resultado.                         |
| RF-011.3 | Gestionar conflictos de sincronización                    | El sistema deberá identificar y notificar conflictos cuando dos dispositivos realicen operaciones incompatibles sobre el mismo lote. La primera operación válida se acepta, las posteriores en conflicto se marcan con estado CONFLICTO para resolución manual.      |
| RF-011.4 | Consultar operaciones pendientes de sincronización        | El sistema deberá permitir al usuario consultar operaciones registradas localmente no sincronizadas (tipo, fecha, monto y estado). El administrador puede consultar además operaciones en conflicto de todos los usuarios.                                           |
| RF-011.5 | Cachear catálogo y datos maestros                         | El sistema deberá mantener disponible localmente el catálogo completo de productos, lotes activos, precios, descuentos y usuarios habilitados, actualizándolos automáticamente con conexión.                                                                         |
| RF-012   | Gestión de Categorías de Producto                         | El sistema deberá permitir al supervisor gestionar las categorías de producto del negocio, ya que cada categoría define su propio umbral de días para alertas de vencimiento.                                                                                        |
| RF-012.1 | Registrar categoría de producto                           | El sistema deberá permitir al supervisor registrar una nueva categoría especificando nombre y días de anticipación para alertas de vencimiento (diasAlertaVencimiento).                                                                                              |
| RF-012.2 | Consultar categorías de producto                          | El sistema deberá permitir al supervisor consultar el listado de categorías registradas con filtros por nombre y estado, mostrando cantidad de productos activos asociados.                                                                                          |
| RF-012.3 | Actualizar categoría de producto                          | El sistema deberá permitir al supervisor modificar nombre y días de alerta de vencimiento. Los cambios afectan los lotes vigentes en la próxima generación de alertas.                                                                                               |
| RF-012.4 | Inactivar categoría de producto                           | El sistema deberá permitir inactivar una categoría solo si no existen productos activos asociados, listando los productos afectados si es necesario.                                                                                                                 |
| RF-013   | Gestión del Negocio                                       | El sistema deberá permitir al administrador gestionar la información y configuración global del negocio, incluyendo parámetros que afectan a todos los usuarios y operaciones.                                                                                       |
| RF-013.1 | Registrar negocio                                         | El sistema deberá permitir el registro inicial de un negocio con nombre comercial, tipo, ciudad, dirección y porcentaje máximo de descuento, creando al primer usuario administrador.                                                                                |
| RF-013.2 | Consultar información del negocio                         | El sistema deberá permitir al administrador consultar la información y configuración actual del negocio.                                                                                                                                                             |
| RF-013.3 | Actualizar información del negocio                        | El sistema deberá permitir al administrador modificar nombre comercial, dirección y porcentaje máximo de descuento. Tipo de negocio y ciudad quedan fijos tras registro inicial.                                                                                     |
| RF-013.4 | Configurar porcentaje máximo de descuento global          | El sistema deberá permitir al administrador configurar el techo máximo de descuento aplicable a cualquier producto del negocio.                                                                                                                                      |
| RF-014   | Análisis Complementario de Rotación                       | El sistema deberá permitir al administrador identificar productos con problemas de rotación para tomar decisiones comerciales como promociones, descuentos o retiro del catálogo.                                                                                    |
| RF-014.1 | Identificar productos de baja rotación                    | El sistema deberá listar los productos cuya velocidad de venta sea inferior a un umbral configurable durante un período, incluyendo stock actual, valor inmovilizado y fecha de última venta.                                                                        |
| RF-014.2 | Identificar productos de alta rotación                    | El sistema deberá listar los productos con mayor velocidad de venta, indicando cantidad total vendida, valor generado y días de cobertura restante del stock.                                                                                                        |
| RF-014.3 | Consultar tendencia de rotación por producto              | El sistema deberá permitir al administrador consultar la evolución de la velocidad de venta de un producto específico en períodos configurables.                                                                                                                     |
| RF-015   | Gestión de Comprobantes de Venta                          | El sistema deberá permitir al cajero generar y entregar el comprobante de venta al cliente en los formatos que el negocio necesite.                                                                                                                                  |
| RF-015.1 | Generar comprobante en formato digital                    | El sistema deberá permitir al cajero generar un comprobante digital en PDF con logo, detalle de productos, cantidades, precios, descuentos, método de pago, cambio, nombre del cajero, fecha y hora.                                                                 |
| RF-015.2 | Compartir comprobante por medios digitales                | El sistema deberá permitir al cajero compartir el comprobante mediante enlace directo, código QR o descarga local para que el cliente pueda conservarlo.                                                                                                             |
